# E-Commerce RFM Customer Segmentation Dashboard

An interactive Power BI dashboard analyzing **3,898 unique e-commerce customers** using **RFM (Recency, Frequency, Monetary)** modeling and custom **DAX** measures to classify customer behavior and guide targeted retention strategies.
## Key Customer Segments
* **Champions:** High-frequency, recent, high-value buyers driving core revenue.
* **Loyal Customers:** Consistent repeat purchasers with strong engagement.
* **Needs Attention (30.3% / 1.18K):** Largest customer segment showing declining purchase frequency—prime target for re-engagement campaigns.
* **At Risk (26.14% / 1.02K):** Previously active customers with high recency gaps requiring win-back offers.
* **Recent Customers & Lost Customers:** New acquisitions to nurture and churned users for post-mortem analysis.

## Tools & Techniques
* **Power BI Desktop:** Interactive KPI cards, donut distribution charts, and segment-level frequency comparisons.
* **DAX:** Custom calculated columns and measures for Recency, Frequency, Monetary scoring, and dynamic segment classification.
